# 页面信息分层

页面优先展示当前出口、自动 / 手动模式、主备状态、关键操作和业务列表。支持信息按需打开，不改变代理配置或选路逻辑。

| 内容 | 位置 |
| --- | --- |
| 当前出口、模式、主备状态、延迟 | 每页顶部的紧凑摘要 |
| 节点与订阅 | 页面主体，首屏优先展示 |
| 地区球体、代理入口、四项完整统计 | “连接详情”侧栏 |
| 全部订阅择优、主订阅优先、主订阅选择 | “调整策略”侧栏 |
| 检测地址、间隔、切换与恢复说明 | “选择规则”侧栏 |
| 编辑订阅、设为主订阅、删除订阅 | 订阅行“更多”菜单 |
| 检测地址、认证、允许网段 | 连接设置中的折叠项 |
| 服务重启 | “服务维护”折叠项 |
| 筛选解释 | 地区与筛选页面的折叠说明 |

## 侧栏与编辑

使用原生 dialog 约束焦点和背景交互，支持关闭按钮、Escape 和背景点击。关闭后恢复到入口按钮。策略未保存时先展示保留 / 放弃提示，继续编辑不丢失草稿。请求失败时侧栏与输入保留。登录失效会关闭弹层并回到登录页。

详情内容继续接收状态刷新；策略草稿与展开的操作菜单不受轮询覆盖。球体仅在打开连接详情且处于可见区域时连续绘制，关闭或进入后台后暂停。
