# 网络控制台界面

此版本在独立代理项目中升级界面，继续使用现有 API 和订阅、筛选、节点选择功能。

## 视觉与交互

- 石墨色背景与薄荷绿强调色，统一侧栏、表单、列表、弹窗和登录页。
- 出口概览展示实际当前节点、来源、地区、检测状态和本机代理入口。
- Canvas 绘制点阵球体、经纬线与轨道；候选节点按识别地区显示标记，当前节点所在地区高亮。
- 出口就绪时显示连接路径动效，订阅更新或节点检测时显示扫描效果，切换出口时短暂高亮概览边框。
- 节点列表展示地区缩写、当前出口高亮、已选择按钮及基于实际延迟的信号标识。
- 页面切换、数值变化、弹窗和通知分别提供短过渡；5 秒状态轮询不重新播放整个页面的进入动画。
- 右上角提供动效开关，记住浏览器偏好；系统减少动态效果设置优先。
- 自动选择按钮持续显示当前启用状态，出口概览显示自动 / 手动模式；节点选择策略展示检测间隔、地址、故障处理和最近检测时间，规则可展开查看。
- 订阅管理提供“全部订阅择优 / 主订阅优先”选择及主订阅快捷按钮；主备角色、实际来源、切换和恢复进度均来自管理服务的运行状态。
- 主页面只保留紧凑出口摘要和业务列表；连接概览、完整统计、策略编辑和规则说明通过侧栏按需呈现。订阅低频操作收进“更多”，连接设置的高级项与说明默认折叠。

球体为近似的地区分布示意，不提供真实出口定位或流量统计。无候选节点、未检测和服务未就绪状态分别展示，不伪造可用数量、速率或流量曲线。

## 文件

| 文件 | 内容 |
| --- | --- |
| `static\index.html` | 页面结构、出口概览、登录页和导航 |
| `static\network.css` | 统一样式、响应式布局、状态与过渡 |
| `static\compact.css` | 信息分层、紧凑布局、侧栏、操作菜单与高级项折叠 |
| `static\effects.js` | 球体、可见性管理、减少动态效果、数值反馈 |
| `static\app.js` | 现有交互和真实状态展示 |
| `static\icons` | 本地 Heroicons SVG，MIT 许可 |

旧界面的三个文件备份在 `data\ui-backup-20261015`。未对正式订阅、代理配置和管理密码进行修改。

- JavaScript 语法检查：`app.js`、`effects.js` 通过。
- 现有管理 API 回归：6 项通过。
